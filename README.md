# Кыргыз тили — 23-сентябрь · Мамлекеттик тил күнү

Одностраничный сайт ко Дню государственного языка Кыргызской Республики.
Работает без интернета и без установки чего-либо: просто откройте `index.html` в браузере.

Три языка: **KG / RU / EN** — переключатель в шапке, выбор запоминается в браузере.

## Оформление

Светлая тема: белый и кремовый фон, тёмный текст. Тёмными остаются только
обложка и подвал — так первый экран смотрится контрастно.
Акценты: **бордо** `#a5182b`, **золото** `#c9962b`, **терракота** `#c9633b`.
Орнаменты из папки `фон` вынесены на фон секций: боковые «крылья» из `фон4`,
красная полоса из `фон1` вдоль края, ковровый фон в разделе викторины.

## Файлы

```
index.html      — разметка и весь текст на трёх языках
styles.css      — оформление (цвета — переменные в самом верху файла)
script.js       — отсчёт, анимации, викторина, игра, переключатель языка
assets/img/     — фоны (скопированы из папок «фон» и «образец»)
assets/people/  — фотографии личностей
люди/, фон/, образец/ — исходные материалы, сайт их не использует
```

портрет по центру. Если файла нет, в карточке показывается орнаментальная
монограмма с инициалами.

## Что легко поменять

- **Текст** — в `index.html`: кыргызский лежит прямо в теге, русский в
  `data-ru="…"`, английский в `data-en="…"` рядом.
- **Вопросы викторины** — массив `QUIZ` в `script.js`.
- **Слова** — массивы `WORDS` (карточки) и `POOL` (игра) в `script.js`.
  В игре каждый раз случайно берутся 8 пар из 14 и раскладываются так,
  чтобы парные карточки не оказались рядом.
- **Цвета** — переменные в начале `styles.css`.
